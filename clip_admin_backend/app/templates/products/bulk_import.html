Cómo funciona

Este proceso permite importar múltiples productos a la vez desde imágenes:

  • Selecciona una categoría para todos los productos
  • Define un patrón de SKU con XXX donde irá el consecutivo (ej: GOD-DEL-XXX)
  • Sube múltiples imágenes (JPG, PNG, WEBP hasta 50MB c/u)
  • El sistema creará un producto por imagen, generará embeddings, actualizará centroides y auto-completará atributos detectables
