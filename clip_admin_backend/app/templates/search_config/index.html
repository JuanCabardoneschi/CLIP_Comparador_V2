¿Cómo funciona la Configuración de Búsqueda?

Este panel te permite ajustar los parámetros principales del buscador visual para controlar la relevancia y cantidad de resultados.

Similitud Visual Mínima

¿Qué hace? Define qué tan parecido debe ser un producto a la imagen subida para aparecer en los resultados.

Rango recomendado: 60-80%

Más alto (80%+): Solo muestra productos MUY similares visualmente. Menos resultados pero más precisos.
Medio (65-75%): Balance entre precisión y variedad.
Más bajo (50-65%): Muestra más opciones, aunque menos parecidas. Más resultados pero menos precisos.

Consejo: Si tus clientes se quejan de "muy pocos resultados", baja este valor. Si ven "productos que no se parecen", súbelo.
Balanceo de Resultados Próximamente

¿Qué hará? Permitirá ajustar el peso de diferentes criterios al ordenar los resultados.

Peso Visual:

Priorizará productos que se parezcan visualmente (color, forma, estilo).

Peso Metadata:

Priorizará productos con atributos coincidentes (marca, color exacto, material).

Peso Business:

Priorizará productos según tu estrategia (stock disponible, destacados, promociones).

Esta funcionalidad estará disponible en la próxima versión del sistema (SearchOptimizer Lite).
Configuración Recomendada

Similitud Visual Mínima: 70% (balance entre precisión y variedad)
